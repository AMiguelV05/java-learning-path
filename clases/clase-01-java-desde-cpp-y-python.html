01 · Historia

Un lenguaje que nació para electrodomésticos

Te va a gustar este dato por tu lado de IoT: Java nació en 1991 para programar aparatos electrónicos, como decodificadores de TV. El problema era que cada aparato tenía un chip distinto, y recompilar C++ para cada uno era un dolor. La solución fue compilar a un formato intermedio (bytecode) y poner en cada aparato una máquina virtual que lo entendiera.

  1. 1991 · Green Project en Sun Microsystems. James Gosling crea un lenguaje llamado Oak (por un roble que veía desde su oficina).
  2. 1995 · Se renombra a Java (por el café de la isla de Java, de ahí la taza del logo). Lema: Write once, run anywhere.
  3. 2006 · Sun libera Java como código abierto: nace OpenJDK.
  4. 2010 · Oracle compra Sun. Desde entonces Oracle es quien dirige Java. Por eso Java pesa tanto en sus entrevistas.
  5. 2014 · Java 8: llegan las lambdas y los Streams. El salto más grande en la historia del lenguaje. (Es la versión que tienes instalada ahorita.)
  6. 2017 · Java empieza a sacar una versión nueva cada 6 meses (marzo y septiembre).
  7. 2021 · Java 17: record, sealed, pattern matching.
  8. 2023 · Java 21: virtual threads, miles de hilos ligeros para servidores.
  9. 2025 · Java 25: puedes escribir programas pequeños sin declarar clase. Es la versión LTS más reciente y la que vas a usar.

LTS = Long-Term Support. Las empresas casi solo usan versiones LTS (los puntos naranjas) porque reciben parches de seguridad durante años. En entrevistas te pueden preguntar "¿qué versión de Java usas y por qué?". Buena respuesta: "una LTS, como la 21 o la 25".

02 · Animación

¿Cómo llega tu código a la CPU?

Compara los tres lenguajes que conoces. Elige uno y dale Reproducir o avanza paso a paso.

La idea clave: C++ se traduce una vez a código máquina de un sistema. Python se interpreta cada vez que corre. Java hace las dos cosas: compila a bytecode (portable) y luego la JVM, mientras corre, detecta el código que más se usa y lo convierte a código máquina optimizado. Eso es el JIT (Just-In-Time compiler), y por eso Java suele ser mucho más rápido que Python. Como estás llevando Compiladores, fíjate: javac es el front-end y el JIT es un back-end que corre en tiempo de ejecución.

03 · Vocabulario

JDK, JRE y JVM: cajas dentro de cajas

JDK · Java Development Kit
Todo lo que necesitas para programar: el compilador javac, el depurador, jshell, javadoc… y adentro, el JRE.
JRE · Java Runtime Environment
Lo necesario para ejecutar programas: las bibliotecas estándar (String, ArrayList, HashMap…) y la JVM.
JVM · Java Virtual Machine
El programa que lee bytecode, lo interpreta, lo compila con el JIT y administra la memoria con el recolector de basura.

Tu caso concreto: en tu PC tienes un JRE de Java 8. Por eso java -version funciona, pero javac no existe. Te falta el JDK, y lo instalamos en el ejercicio 0.

06 · Cuidado

6 trampas para quien viene de C++ y Python

1 · == con Strings

String a = new String("hola");
String b = new String("hola");
a == b       // false 😱
a.equals(b)  // true ✅

== compara referencias (si es el mismo objeto). Para comparar contenido usa .equals(). Es la pregunta de entrevista más común sobre Java.

2 · División entera

int x = 7 / 2;        // 3, no 3.5
double y = 7 / 2;     // 3.0 😱
double z = 7 / 2.0;   // 3.5 ✅

Igual que en C++. En Python, / siempre da decimal; aquí no.

3 · Strings inmutables

String s = "";
for (...) s += x;  // lento: crea un String nuevo cada vez
StringBuilder sb = new StringBuilder();
for (...) sb.append(x); // ✅

Un String nunca cambia. Para construir texto dentro de un ciclo usa StringBuilder.

4 · Arreglos de tamaño fijo

int[] a = new int[5];   // no crece
a.length                  // sin ()
ArrayList<Integer> l = new ArrayList<>();
l.size()                  // con ()

Si necesitas que crezca, como una lista de Python, usa ArrayList. Fíjate que se escribe Integer y no int: las colecciones solo guardan objetos.

5 · Desbordamiento silencioso

int big = Integer.MAX_VALUE;
big + 1   // -2147483648 😱

En Python los enteros crecen sin límite. En Java no: dan la vuelta sin avisar. Es un error típico en problemas de entrevista (por ejemplo, (lo + hi) / 2).

6 · char ≠ String

char c = 'a';     // comillas simples
String s = "a";   // comillas dobles
s.charAt(0) == c   // true

En Python 'a' y "a" son lo mismo. En Java son tipos distintos.

08 · Para tus apuntes

Resumen en 10 líneas

  1. Java nació en 1991 (Sun) para electrodomésticos; Oracle lo dirige desde 2010.
  2. Flujo: .java → javac → .class (bytecode) → JVM → intérprete + JIT → CPU.
  3. El bytecode es portable: write once, run anywhere.
  4. JDK ⊃ JRE ⊃ JVM. Para programar necesitas el JDK.
  5. Usa versiones LTS: 21 o 25.
  6. Tipado estático, memoria automática (recolector de basura), todo dentro de clases.
  7. 8 primitivos (byte short int long float double char boolean); todo lo demás es objeto por referencia.
  8. Strings: compáralos con .equals(); para concatenar en ciclos usa StringBuilder.
  9. Arreglo = tamaño fijo (.length); ArrayList = dinámico (.size()).
  10. Herencia simple con extends + múltiples interface.
